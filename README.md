# SPF Fault Diagnosis Dataset

## Overview

This dataset is constructed using physics-based simulations for fault diagnosis of superplastic forming (SPF) equipment.

## Dataset Structure

The dataset contains six fault categories:

- Normal
- Overheat
- Partial_Failure
- Leakage
- Open_Circuit
- Short_Circuit

Each sample contains three thermocouple time-series CSV files and a folder of simulated temperature-field images.

## Data Description

- `TC170.csv`: Thermocouple time-series data.
- `TC340.csv`: Thermocouple time-series data.
- `TC520.csv`: Thermocouple time-series data.
- `temperature_frames/`: Simulated temperature-field images.

## Notes

The temperature-field images are generated by physical simulation and are not real infrared thermal images.

## Intended Use

This dataset supports research on multimodal fault diagnosis under limited fault-sample conditions.
